eduroamKR database

대한민국(kr01) eduroam 참여기관 데이터입니다. 소스 저장소의 YAML 에서 자동 생성되며, 기관 정보가 바뀌면 몇 분 안에 여기가 갱신됩니다.

제출 파일

eduroam database specification v2.0.1 을 따릅니다. GÉANT eduroam monitor 가 db.eduroam.kreonet.net 의 이 주소를 수집합니다.

  • general/institution.xml — 참여기관 전체
  • general/ro.xml — NRO 정보

사이트용 데이터

NRO 안내 사이트가 지도와 기관 목록을 그리는 데 씁니다. 제출 XML 과 달리 모양을 바꿀 수 있습니다.

  • site/institutions.json — 기관 목록, 가입년도, 캠퍼스
  • site/locations.geojson — 지도 지점 (GeoJSON)

기관 로고

logo/<realm>.<확장자> 로 가져갑니다. 확장자는 기관마다 다르니 저장소의 logo/ 목록에서 확인하세요.

각 로고의 권리는 해당 기관에 있습니다. eduroam 참여기관을 알아보게 하는 식별 표시로만 담아 두며, 기관을 보증하거나 후원 관계를 나타내지 않습니다.

고치기

기관 정보를 등록하거나 고치려면 저장소의 inst.d/ 에 Pull Request 를 보내주세요. 자기 기관 파일 하나만 담으면 됩니다.
